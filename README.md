# 📱 Mobile Sales Analytics Dashboard \| Power BI

## 📊 Project Overview

This project is an interactive **Mobile Sales Analytics Dashboard**
developed using **Microsoft Power BI**.

The dashboard provides a consolidated view of mobile sales performance
and enables analysis across **mobile models, brands, payment methods,
cities, months, days, and time periods**.

The project demonstrates how raw sales data can be transformed into
meaningful business insights using **Power Query, DAX, data modeling,
and interactive Power BI visualizations**.

## 🛠️ Tools & Technologies

-   **Microsoft Power BI** -- Dashboard development, KPIs, interactive
    visuals and reporting
-   **Power Query** -- Data cleaning and transformation
-   **DAX** -- Measures and business calculations
-   **Data Modeling** -- Relationships and analytical model development
-   **Excel / CSV** -- Data source and preparation

# 📈 Power BI Dashboard Pages

## 1. Main Dashboard

Provides an overall summary of mobile sales performance.

**Key KPIs:** - Total Sales - Transactions - Total Quantity - Average
Price

**Analysis includes:** - Sales by City - Total Quantity by Month -
Customer Ratings - Transactions by Payment Method - Top 3 Mobile Models
by Total Sales - Sales by Day Name - Brand-wise sales and transactions

## 3. Same Period Last Year Analysis

This page compares current sales performance with the **Same Period Last
Year (SPLY)**.

**Analysis includes:** - Total Sales vs Same Period Last Year -
Year-wise comparison - Quarter-wise comparison - Month-wise comparison -
Detailed sales table - Current-period vs previous-period performance

This helps evaluate **year-over-year growth** and identify changes in
sales performance.

# 📐 Important Business Metrics

  -----------------------------------------------------------------------
  Metric                              Purpose
  ----------------------------------- -----------------------------------
  Total Sales   --                      Measures overall sales generated

  Transactions  --                      Measures the number of sales
                                      transactions

  Total Quantity --                     Measures total mobile units sold

  Average Price  --                     Measures average selling price

  MTD Sales      --                     Tracks sales accumulated during the
                                      current month

  Same Period Last Year --               Compares current performance with
                                      the corresponding previous period

  Customer Ratings  --                  Evaluates customer satisfaction

  Sales by Brand   --                   Identifies high-performing brands

  Sales by Model   --                   Identifies top-performing mobile
                                      models

  Payment Method   --                   Analyzes transaction contribution
                                      by payment type
  -----------------------------------------------------------------------

# 👨‍💻 Project Summary

The **Mobile Sales Analytics Dashboard** demonstrates how Power BI can
transform raw sales data into an interactive business intelligence
solution.

The project combines **Power Query for data preparation, data modeling
for structured analysis, and DAX for business calculations**. The final
dashboard provides insights into sales, transactions, quantity, pricing,
customer ratings, brands, mobile models, payment methods, and time-based
performance.
